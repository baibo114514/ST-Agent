# 投诉建议 · 用户操作手册

## 一、功能简介

「投诉建议」用于提交您对园区/公寓的意见或问题，支持文字描述、上传图片，并可填写投诉区域、问题类型、房间、地址、姓名、联系方式等信息后提交，服务方将尽快处理。

页面顶部引导文案：**「请填写你的投诉建议,我们会尽快处理」**。

---

## 二、表单字段说明

| 字段 | 说明 |
|------|------|
| 投诉建议内容 | 多行文本输入框，用于填写投诉/建议内容，最多可输入 250 字 |
| 图片上传 | 上传相关图片佐证，最多上传 6 张 |
| 投诉区域 | 单选：户内 / 公共（默认选中「户内」） |
| 问题类型 | 单选：投诉 / 建议 |
| 房间 | 输入房间信息 |
| 地址 | 占位「请输入您的详细地址」 |
| 姓名 | 占位「请输入您的姓名」 |
| 联系方式 | 占位「请输入联系方式」 |
| 提交 | 页面底部「提交」按钮 |

---

## 三、用户操作步骤

1. 进入「投诉建议」页面，查看顶部引导文案。
2. **填写投诉建议内容**：在多行输入框内输入具体内容（最多 250 字，输入框右下角实时显示字数）。
3. **上传图片（可选）**：点击图片上传区域，选择需上传的图片（最多 6 张）。
4. **选择投诉区域**：在「户内 / 公共」中单选。
5. **选择问题类型**：在「投诉 / 建议」中单选。
6. **填写房间**：输入对应的房间号/房间信息。
7. **填写地址**：输入详细地址。
8. **填写姓名**：输入您的姓名。
9. **填写联系方式**：输入联系方式，便于服务方联系。
10. 核对信息无误后，点击底部「提交」按钮提交。

---

## 四、填写提示与注意事项

- **内容长度**：正文最多 250 字，超出需精简。
- **图片数量**：最多上传 6 张图片。
- **投诉区域**：按问题发生位置选择「户内」或「公共」。
- **问题类型**：按诉求性质选择「投诉」或「建议」。
- **联系方式**：请填写真实有效联系方式，便于跟进处理。
