# 环境治理 · 用户操作手册

## 一、服务简介

「环境治理」由专业人员进行环境消杀/除醛等作业，服务主题：**专业治理，打造健康办公环境**。环境治理包含**环境消杀**与**室内空气治理**两大方向。

---

## 二、环境消杀

- **说明**：切断病原体传播，打造卫生的办公环境和健康的生活环境，一方面需要做好基础卫生和防鼠防蝇，一方面需要用生化、物理的方法来控制。消杀服务通常由专业的消杀公司来完成。
- **消杀内容**：
  - **四害消杀**：对鼠、蝇、蚊、蟑进行消杀；
  - **空气净化**：净化空气。
- **补充说明**：用专业药剂对办公区「四害」（鼠、蝇、蚊、蟑）和物品及空气中的病原体进行清理和消杀，避免病毒和细菌的传播引发健康隐患，打造卫生安全的办公环境。

## 四、室内空气治理

### 解决方法
专业环境机构**定期上门治理**，针对办公区域和空气污染源进行综合强效降解和净化，机构资质齐全、设备先进，可**预约上门体验**。

### 服务内容（四类）
1. **甲醛专项治理**
2. **板材专项治理**
3. **异味专项治理**
4. **综合治理**

### 验收有标准 服务有保障
- 治理后室内空气中的**甲醛、苯系物、TVOC、氨**的浓度达到国家标准，客户可**委托有CMA资质的第三方进行复检**。
- 参照《民用建筑工程室内环境污染控制标准》**GB50325-2020**，各项污染物浓度限值如下：

| 污染物 | 浓度限值 |
|--------|----------|
| 甲醛 | ≤0.08mg/m³ |
| 苯 | ≤0.09mg/m³ |
| 甲苯 | ≤0.20mg/m³ |
| 二甲苯 | ≤0.20mg/m³ |
| TVOC | ≤0.50mg/m³ |

## 六、用户操作步骤

### 环境消杀
1. 线上预约消杀服务。
2. 服务方制定消杀方案（明确四害消杀/空气净化范围）。
3. 专业人员上门服务（使用符合国标的消毒液等）。
4. 服务后跟进，确认办公环境安全卫生。

### 室内空气治理
1. 在线提交工单，客户经理对接需求、勘查现场实际情况。
2. 选择治理内容（甲醛/板材/异味专项治理或综合治理）。
3. 确认治理方案并报价后签订合同。
4. 专业机构定期上门实施治理。
5. 治理后验收，必要时委托有CMA资质的第三方复检，参照 GB50325-2020 标准核对浓度限值。
6. 完成满意度调查。
