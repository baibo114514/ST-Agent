# 资质办理

## 功能概述

「资质办理」是 E-SPACE APP「服务 → 产业服务」板块下的资质代办服务入口，以标准化、智能化、规模化为目标，致力于为大中小企业提供**全生命周期**的资质代办类服务办理。

## 服务内容

- **管理体系代办**
- **软件成熟模型代办**
- **知识产权贯标**
- **ITSS3\4 运维代办**
- **各项认证代办**

## 服务标准

| 标准 | 说明 |
|------|------|
| 专业顾问 | 团队专业，平均 3 年以上工作经验，办理案例过万 |
| 快速高效 | 简单快捷，资料完整 24 小时内开始，前一项办理完成后立即启动下一流程 |
| 信息保密 | 签订保密协议、保障信息安全 |
| 明码标价 | 价格透明，明码实价，签订协议后不收取任何附加费用 |
| 透明可视 | 服务公开，根据合同严格操作，服务流程可视化 |

## 服务流程（9 步闭环）

1. 在线提交工单 → 2. 客户经理对接需求 → 3. 一站式解决方案并报价 → 4. 客户确认方案及报价 → 5. 签订合同 → 6. 实施办理 → 7. 办理完成 → 8. 工单完成 → 9. 满意度调查

## 申请表单填写

提交资质办理需求时，需填写：**具体要求说明**（500 字以内）、**所属企业**（*必填）、**地址**（*必填）、**联系人**（*必填）、**联系方式**（*必填）、经营范围、主营产品、技术领域、行业类型。

填写完成后点击底部「**服务提交**」按钮；右下角提供「**立即联系**」按钮。
