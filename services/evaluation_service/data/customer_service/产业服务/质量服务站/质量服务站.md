# 质量服务站

## 功能概述

「质量服务站」是 E-SPACE APP「服务 → 产业服务」板块下的质量基础设施服务入口，由「湖北省标准化与质量研究院（HBSQI）」提供服务，下设**标准化服务、检验检测、计量服务、认证认可**四大模块，为园区企业提供「一站式」质量服务。

---

# 模块一：标准化服务

联合湖北省标准化与质量研究院，协助企业编制企业标准、团体标准，辅导企业申报地方标准、国家标准、行业标准及国际国外标准。

## 服务内容
1. **企业标准编制**：由企业内部需要协调统一的技术要求、管理要求和工作要求制定的标准。有利于抢占市场先机、打造企业品牌、提高企业竞争力、引导行业发展。
2. **团体标准编制**：由协会制定，提高产品信用度及权威性、提高企业竞争力、促进贸易往来，有机会申报国家级奖项。
3. **地方标准申报辅导**：由地方标准化主管机构或专业主管部门批准、发布，促进地方经济发展，提升保护传承文化遗产的质量。
4. **国家标准申报辅导**：引导行业发展方向，提高市场核心竞争力，树立标杆企业形象及品牌影响力，领取政府补贴并享受国家福利政策。
5. **行业标准申报辅导**：使企业拥有行业规则话语权，获取市场先机，提升品牌形象，赢得更高发展平台。
6. **国际国外标准申报辅导**：国际标准在世界范围内统一使用，有利于促进技术进步、提高产品质量和效益，促进贸易自由化及国际经济技术交流合作。

## 服务流程（6 步闭环）
STEP1 在线提交工单 → STEP2 标准院对接需求 → STEP3 标准院实施办理 → STEP4 办理完成 → STEP5 工单完成 → STEP6 满意度调查

# 模块二：检验检测

## 服务介绍
检验检测是对检验项目中的性能进行量测、检查、试验等，并将结果与标准规定要求比较，以确定每项性能是否合格所进行的活动。

## 检测领域
- **金属领域**：钢材制品、轨道交通、不锈钢、焊接工艺等。
- **橡胶塑料领域**：橡胶胶管、塑料管、塑胶跑道等。
- **化工领域**：涂料油墨、能源电池、纺织品等。
- **民生领域**：食品、生活用品、植物等。

## 服务优势与收益
通过检验检测可提高产品质量和生产效率、提高投资效益、提升客户满意度。

## 服务流程（6 步闭环）
STEP1 在线提交工单 → STEP2 标准院对接需求 → STEP3 标准院实施办理 → STEP4 办理完成 → STEP5 工单完成 → STEP6 满意度调查

# 模块三：计量服务

联合湖北省标准化与质量研究院，提供计量技术支持服务，帮助企业建立完善计量标准，服务企业研发与生产环节，助力企业提质增效。

## 服务内容
1. **计量检测**：针对企业业务进行量具、仪器设备等的计量检定、校准和测试服务，提高产品质量保证、降低原材料和能源消耗、提高经济效益。
2. **建立社会计量标准**：强化企业计量设备规范化与标准化管理，提高设备及仪器使用准确性，避免误差影响产品质量。
3. **建立计量管理体系**：确保产品过程受控，是生产经营过程中科学的监控过程，须贯穿企业生产全过程。

## 服务流程（6 步闭环）
STEP1 在线提交工单 → STEP2 标准院对接需求 → STEP3 标准院实施办理 → STEP4 办理完成 → STEP5 工单完成 → STEP6 满意度调查

# 模块四：认证认可

联合湖北省标准化与质量研究院，提供全链条、全方位、全过程质量基础设施综合服务，为园区企业提供标准化与质量相关的「一站式」认证服务。

## 服务内容

**（1）管理体系认证**（部分列举）：
- 质量管理体系认证（ISO9001）：改善内部管理、提高客户满意度和产品知名度；招投标中通过 ISO9001 是硬性要求，贯标企业可享 1.5-2 分加分。
- 环境管理体系认证（ISO14001）、信息安全管理体系认证（ISO27001）、职业健康安全管理体系认证（ISO45001）、能源管理体系认证（ISO50001）、信息技术服务管理体系认证（ISO20000）、资产管理体系认证（ISO55001）、道路交通安全管理体系认证、食品安全管理体系认证（ISO22000）、健康安全与环境管理体系认证（HSE）、社会责任管理体系认证（SA8000）、企业诚信管理体系认证（ISO31950）、商品售后服务管理体系认证、合规管理体系（ISO37301）等。

**（2）服务认证**：
- 高技术服务业业务认证（含信息服务、电子商务服务、检验检测服务、技术服务、研发与设计服务、科技成果转化服务、知识产权及相关法律服务等 9 大类）、物业服务认证、人力资源外包服务认证、综合能源服务认证。

**（3）产品认证**：
- 绿色建材产品认证、绿色纺织产品认证等。

**（4）国推认证**（以页面实际展示为准）。
